**Задача:** меню настроек — гармоничное, сгруппированное, во всю ширину сайта по центру, с анимацией, оптимизировано для телефонов, без пустых областей.

**Что сделано:**
- Полноширинная центрированная панель (до 1180px) вместо узкого прямоугольника.
- 7 сгруппированных карточек: Язык · Тема · Модель данных / Единицы · Производительность · Действия / Юридическая информация.
- Исправлены галочки (инлайн, не перекрывают подписи) и обрезанные надписи.
- Секции выровнены по высоте: «Единицы» — вертикальный список, «Действия» — компактные плитки 2×2.
- Мобильная версия — bottom-sheet (шторка снизу), крупные тап-зоны.
- Анимация появления карточек и пружинная анимация галочек.

**Последний фикс (пустая полоса между рядами, твой красный маркер):**
- Причина найдена: карточки в ряду имели разную высоту — (а) широкая плитка «Установить» появлялась через 3 секунды и растягивала «Действия» на 3 ряда; (б) сетка `auto-fit minmax(148px)` на средних ширинах сворачивалась в 1 колонку и тоже давала 3 ряда.
- Исправлено: (а) «Установить» переехала в заголовок карточки компактной «пилюлей» (больше не меняет высоту сетки); (б) сегменты теперь всегда ровно 2 колонки → каждая карточка всегда 2 ряда (изолированно); (в) карточки растягиваются на высоту ряда (`align-items: stretch`) — пустой полосы не может быть физически.
- **Осталось только визуальное подтверждение** — в песочнице нет браузера (скачивание Chromium заблокировано сетью), поэтому прошу один скриншот панели после обновления (кэш: css `v=56`, SW `livesky-v1.4-clouds-v21`).
