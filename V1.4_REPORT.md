## Этап 1 — «Температура · 24 часа» ✅

**Задача:** блок «Температура · 24 часа» и «Следующие 24 часа» были двумя разными блоками → объединить в один с переключателем.

**Что сделано:**
- Один блок с двумя режимами: **График** (температурная кривая) и **Часы** (почасовая таблица) — переключение одним касанием.
- Маркер **«Сейчас»** на графике — всегда видно текущий момент.
- Плавная анимация смены режимов.
- **Исправлен баг быстрого переключения** (быстрые клики «График → Часы → График» могли оставить пустой блок) — теперь переключения сериализованы токеном `paneSwitchToken`, гонки исключены.
- Попутно: корректный пересчёт температуры при смене единиц, умный график осадков «когда закончится / когда начнётся» (`Rain 14:00–17:45`).

**Файлы:** `docs/js/modules/04-chart.js`, `docs/css/app.css`, `tests/smoke.js`.

## Этап 2 — Карта осадков ✅ (v13)

**Задача:** полноценная карта осадков: слайдер по времени, покрытие России, направление дождя, ETA; гибрид RainViewer + NASA IMERG + собственный nowcast; без «квадратной» пикселизации; быстро на телефонах.

**Что сделано:**
- **Три источника в гибриде:** RainViewer (радар) + **NASA IMERG** (спутниковая оценка осадков, покрывает всю планету, включая Россию) + **собственный nowcast** (экстраполяция движения облаков на ближайшие часы).
- **Слайдер по всему миру** — можно «проиграть» осадки вперёд/назад по времени.
- **Направление дождя и ETA** — прогноз, когда дождь дойдёт до выбранной точки и откуда.
- **Пикселизация исправлена** — облака рендерятся с размытием и интерполяцией (v13), а не квадратами.
- **Производительность на телефонах** — отдельный «лёгкий» режим для слабых устройств (меньше тайлов, слабее размытие), кэш тайлов до 96 штук.
- Валидные источники подтверждены по официальным каталогам (GIBS/NASA, RainViewer).

**Файлы:** `docs/js/modules/11-map-radar.js` (~1300 строк), `docs/css/app.css`, `tests/smoke.js`.

## Этап 3 — Размер репозитория (42 МБ)

**Диагностика (полностью готова, подробно в `REPO_SIZE_REPORT.md`):**

| Что | Размер |
|---|---|
| Рабочее дерево (код, картинки, шрифты) | **8,4 МБ — норма** |
| `node_modules` | 43 МБ, **в Git не входит** |
| Репозиторий целиком (что GitHub показывает) | 42,6 МБ |
| **Причина: мусор в истории Git** | **≈38,7 МБ** |

**Виновники** — файлы, залитые через GitHub и позже удалённые, но оставшиеся в истории: два Picsart-PNG (~23 МБ), `LiveSky-debug.apk` (5.9 МБ), два Picsart-JPG (~9.4 МБ) и мелочь. Если эти файлы удалить из истории — репозиторий станет **~4–5 МБ**.

**Что осталось (решение за тобой):** чистка требует переписывания истории (`git filter-repo` + force-push). По нашему правилу историю без твоего согласия не трогаю. Варианты:
1. **Чистить** — минус 38,7 МБ. Минусы: у всех, кто клонировал, сломается `git pull` (нужен re-clone), пересоздать тег `v2.0.0-android-beta.1`, сбросятся кэши GitHub Actions.
2. **Оставить как есть** — 42 МБ влияет только на скорость клонирования, на сайт/APK/CI не влияет.

Рядом с картой/графиком появляется совет: **«Дождь скоро закончится»** (если nowcast показывает, что осадки уходят) или **«Дождь придёт через N минут»** (если дождь движется к точке). Работает на основе собственного nowcast — даже когда внешние источники молчат.

## Бонус 2 — Панель настроек ✅

**Задача:** меню настроек — гармоничное, сгруппированное, во всю ширину сайта по центру, с анимацией, оптимизировано для телефонов, без пустых областей.

**Что сделано:**
- Полноширинная центрированная панель (до 1180px) вместо узкого прямоугольника.
- 7 сгруппированных карточек: Язык · Тема · Модель данных / Единицы · Производительность · Действия / Юридическая информация.
- Исправлены галочки (инлайн, не перекрывают подписи) и обрезанные надписи.
- Секции выровнены по высоте: «Единицы» — вертикальный список, «Действия» — компактные плитки 2×2.
- Мобильная версия — bottom-sheet (шторка снизу), крупные тап-зоны.
- Анимация появления карточек и пружинная анимация галочек.

**Последний фикс (пустая полоса между рядами, твой красный маркер):**
- Причина найдена: карточки в ряду имели разную высоту — (а) широкая плитка «Установить» появлялась через 3 секунды и растягивала «Действия» на 3 ряда; (б) сетка `auto-fit minmax(148px)` на средних ширинах сворачивалась в 1 колонку и тоже давала 3 ряда.
- Исправлено: (а) «Установить» переехала в заголовок карточки компактной «пилюлей» (больше не меняет высоту сетки); (б) сегменты теперь всегда ровно 2 колонки → каждая карточка всегда 2 ряда (изолированно); (в) карточки растягиваются на высоту ряда (`align-items: stretch`) — пустой полосы не может быть физически.
- **Осталось только визуальное подтверждение** — в песочнице нет браузера (скачивание Chromium заблокировано сетью), поэтому прошу один скриншот панели после обновления (кэш: css `v=56`, SW `livesky-v1.4-clouds-v21`).
