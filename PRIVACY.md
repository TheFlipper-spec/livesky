# Политика конфиденциальности — LiveSky Weather Pro

**Сервис LiveSky (Web & Android) · Версия 2.0**

> Сервис LiveSky уважает вашу конфиденциальность. Приложение может запрашивать доступ к данным о вашем местоположении (геолокации) исключительно в момент использования для обработки запроса к внешним метеорологическим API (например, Open-Meteo) и предоставления точного локального прогноза погоды. Сервис не сохраняет историю перемещений и не связывает координаты с личностью пользователя. Координаты не сохраняются на серверах LiveSky. Они передаются исключительно доверенным внешним провайдерам API (включая, но не ограничиваясь: Open-Meteo, Nominatim, RainViewer) строго в момент использования приложения для предоставления метеоданных и обратного геокодирования. Данные не профилируются и не передаются в маркетинговых целях. Использование приложения подразумевает согласие с данной политикой обработки технических геоданных.

## 1. Использование геоданных

При нажатии кнопки определения геолокации или при первом запуске приложения запрашивается разрешение на доступ к координатам устройства (широта и долгота). Эти данные используются исключительно для:

- получения локального прогноза погоды, индекса качества воздуха и данных об осадках;
- отображения названия населенного пункта через API обратного геокодирования;
- позиционирования карты осадков на текущей точке.

Координаты не сохраняются на серверах LiveSky. Они передаются исключительно доверенным внешним провайдерам API (включая, но не ограничиваясь: Open-Meteo, Nominatim, RainViewer) строго в момент использования приложения для предоставления метеоданных и обратного геокодирования. Данные не профилируются и не передаются в маркетинговых целях.

## 2. Внешние метеорологические API

Приложение LiveSky функционирует на стороне клиента (Client-Side) и обращается к открытым и проверенным сервисам:

- **Open-Meteo API** — расчет погодных моделей и индексов качества воздуха (не собирает персональные данные);
- **Nominatim / OpenStreetMap** — обратное геокодирование (определение названия населенного пункта);
- **RainViewer API** — радарные карты осадков в реальном времени;
- **MapLibre GL / OpenStreetMap** — отображение картографической подложки.

## 3. Локальное хранение (LocalStorage & Cache)

Приложение сохраняет на вашем устройстве следующие настройки:

- выбранный язык интерфейса, цветовая тема и единицы измерения;
- список избранных и недавних городов для быстрого переключения;
- кеш последнего полученного прогноза для поддержки офлайн-режима;
- факт принятия настоящего соглашения и политики конфиденциальности (включая версию принятых документов и отметку времени).

Данные настройки не синхронизируются со сторонними серверами и могут быть полностью очищены в настройках браузера или приложения.

## 4. Уведомления

Погодные уведомления о резких изменениях и опасных погодных явлениях формируются локально на вашем устройстве без использования сторонних рекламных трекеров.

## 5. Согласие

Доступ к интерфейсу приложения предоставляется только после явного подтверждения согласия с настоящей Политикой конфиденциальности и Пользовательским соглашением. До подтверждения интерфейс заблокирован. При обновлении версии юридических документов согласие запрашивается повторно.
