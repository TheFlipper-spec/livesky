## ✅ Дополнительно: Smart Visibility v2 — «шедевр оптимизации»

`SECTION_MANAGER` в `docs/js/app.js` переработан из декоративного в реальный механизм разгрузки:

- **Настоящее удаление тяжёлого DOM** (`unload`): у далёких секций (chart / hourly / daily / lifestyle) карточка **отсоединяется** от документа и заменяется лёгким скелетоном `.section-skeleton-box` (высота измеряется у карточки → скролл не прыгает). Раньше DOM не удалялся вовсе — только менялся `backdrop-filter`.
- **Мгновенное восстановление** (`mount`): при возврате секции кешированная карточка вставляется обратно **без перерисовки**, если данные не менялись (нет мигания и лишней работы).
- **Ленивый re-render** (`renderSection` + флаг `dirty`): тяжёлые рендеры chart/hourly/daily идут через менеджер; разгруженные секции при обновлении данных **не перестраивают DOM**, а помечаются «грязными» и перерисовываются только когда пользователь к ним возвращается.
- **Адаптивный debounce** (`unloadDelay`): в Eco / low-режиме (или при слабом устройстве по FPS-детектору) разгрузка срабатывает через ~1 с вместо 4 с — off-screen DOM освобождается почти сразу.
- **Без «флеша»** при восстановлении: у разгруженных секций не повторяется enter-анимация (opacity остаётся 1).

Проверено выделенным harness-скриптом (jsdom): рендер при загрузке → unload (карточка отсоединена, скелетон на месте) → `renderAll()` **пропускает** пересборку пока секция разгружена → activate (карточка возвращена, контент свежий). Все проверки + `tests/smoke.js` проходят.
