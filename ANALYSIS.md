# LiveSky — анализ развития проекта

Дата: 14 августа 2026 · Ветка: `arena/019ffd46-livesky` · PR: #2

## Что было в начале

Единственный файл `docs/index.html` (~2200 строк, 117 КБ) на Tailwind CDN + Leaflet:

| Аспект | Было | Стало |
|---|---|---|
| Архитектура | 1 файл HTML со всем кодом внутри | `index.html` + `css/app.css` + `js/i18n.js` + `js/app.js` + `tests/smoke.js` |
| CSS | Tailwind CDN (предупреждение в консоли, скачок стилей при загрузке) | Собственная дизайн-система на CSS-токенах |
| Темы | Тёмная/светлая через ~40 `!important`-хаков | 3 темы (адаптивная/тёмная/светлая) на токенах, без хаков |
| Часовые пояса | «Текущий час» искался по UTC — данные «уезжали» на ±N часов | Всё считается в локальном времени города (`Intl` + `timezone=auto`) |
| УФ-индекс | Не запрашивался у API (всегда 0/Low) | Запрашивается, показывается с описанием уровня |
| Восход/закат | Брался `daily[0]` = данные 16-дневной давности | Берётся «сегодня» из массива с `past_days` |
| Карта | Leaflet + CARTO, светлая/тёмная подложка | MapLibre GL: векторные стили → надёжные растровые тайлы с фолбэком OSM, пульсирующий пин, полёты камеры |
| Ошибки сети | `alert()` и бесконечный загрузчик | Таймауты всех запросов, watchdog загрузчика, тосты с «Повторить», аварийная панель, graceful degradation |
| Настройки | 4 кнопки в шапке | Одно меню (язык, тема, единицы, модель, геолокация, полноэкран, обновить) |
| Кеш браузера | Без версий (устаревший код ломал запуск) | Версионирование ассетов `?v=N` |
| Тесты | Отсутствовали | 89 проверок: рендеринг, модалки, темы, поиск, отказы сети, кеш-миксы |

## Ключевые исправления багов по ходу работы

1. **Выпадающие списки прятались за карточками** — анимация шапки делала её stacking-контекстом; решено `z-index` + плотный фон панелей
2. **`16°°`** — дублирующий знак градуса убран
3. **«Ощущается» в двух местах** — оставлена одна плитка в метриках
4. **«Загадочная 3-ка» у ветра** — это была буква «З» (Запад); теперь полное слово + порывы ветра
5. **Scrim затемнял/размывал весь экран** — полностью удалён
6. **Пустая карта** — векторные тайлы не загрузились; возврат на растровые CARTO + фолбэк OSM + заглушка
7. **Случайная смена города** — клики перехватывались закрытой полноэкранной картой + автовыпадающий список избранного; модалка стала полностью инертной, список открывается с задержкой, «период тишины» после закрытия оверлеев
8. **Диссонанс дождя** — «Вероятность сейчас N%» рядом с температурой (при дожде: «Закончится в HH:MM · ещё Xч Yм») + плитка «Дождь сегодня»
9. **Тултип графика обрезался сверху** — заменён детальной панелью под графиком + направляющая линия с точкой
10. **«Макс. дождь за 24ч» непонятен** — заменён на «Дождь сегодня»

## Что появилось нового

- Canvas-эффекты погоды: дождь, снег, туман, облака, звёзды с метеорами, молнии
- Интерактивный график 24 ч с осадками + детальная панель (температура, осадки, ветер, порывы, влажность)
- Солнечная дуга с позицией солнца/луны, долготой дня, фазой луны, золотым часом
- Качество воздуха: AQI-кольцо, 4 загрязнителя, **модалка с анимированным трендом AQI на 24 ч, спарклайнами загрязнителей и рекомендациями по здоровью**
- 16-дневный прогноз + история с температурными диапазонами
- LifeSky-активности (бег / мойка / прогулка) с 7-дневным анализом слотов
- Избранное + недавние города, миграция данных из v1, автодополнение с навигацией стрелками
- Тренд давления, УФ-индекс, высота над уровнем моря, фаза луны
- Автообновление каждые 15 минут, защита от гонок запросов, `prefers-reduced-motion`
- Премиальный загрузчик (орбитальная анимация, шиммер, прогресс-бар, «зум + расфокус» на выходе)
