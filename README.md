## ✨ Возможности

### 🌍 Погода и данные
- **Живой фон** — градиенты и canvas-эффекты под текущую погоду: дождь, снег, туман,
  облака, звёзды с падающими метеорами, молнии при грозе
- **Текущая погода** + 8 метрик: ощущается, ветер с порывами, влажность, видимость,
  давление с трендом, точка росы, УФ-индекс, осадки
- **Точность прогноза**: режим «Авто» использует `best_match` (модель, которую
  Open-Meteo считает самой точной для города), а базовая модель выбирается по региону
  (ECMWF/IFS для Европы, GFS для Северной Америки); в ручных режимах выбранная модель
  дополняется `best_match` как запасной. Текущая температура и «ощущается»
  **интерполируются** между часовыми срезами — цифра плавная, а не «застревает» на часе
- **График температуры на 24 часа** с осадками и интерактивной панелью деталей
- **Почасовой прогноз** на 24 часа и **16-дневный прогноз + история за 16 дней**
- **Качество воздуха**: европейский индекс AQI, тренд на 24 часа, спарклайны загрязнителей,
  рекомендации по здоровью
- **Солнечная дуга** — восход/закат, долгота дня, фаза луны, «золотой час»
- **LifeSky-активности** — лучшие слоты для бега, мойки авто и прогулок с оценкой 0-100

### 🗺️ Карта и радар
- Карта на **MapLibre GL** с надёжными тайлами (CARTO + фолбэк OSM), выбор точки кликом
- **Радар осадков (RainViewer)** поверх полноэкранной карты: таймлайн, слайдер по кадрам
  прошлого + nowcast, play/pause, легенда интенсивности

### 🧠 Smart Visibility — оптимизация рендеринга
- **Секции рендерятся по мере скролла** — каждая секция получает состояние:
  `active` (в viewport), `inactive` (далеко), `unloaded` (максимально далеко)
- **Debounced unloading** — при быстром скролле не дёргается (4 сек буфер;
  в Eco/low-режиме разгрузка срабатывает быстрее)
- **content-visibility: auto** — браузер пропускает рендеринг/layout/paint
  off-screen секций (основной выигрыш по CPU/GPU)
- **Реальное удаление тяжёлого DOM** — у далёких секций карточка отсоединяется
  от DOM и заменяется лёгким скелетоном (высота сохраняется, скролл не прыгает);
  при возврате карточка вставляется обратно без перерисовки, если данные не менялись
- **Ленивый re-render** — при обновлении данных разгруженные секции не перестраивают
  DOM, а помечаются «грязными» и перерисовываются только когда пользователь к ним
  возвращается
- **Интеграция с существующей FPS-системой** — в Eco-режиме отключаются все анимации секций

### 📲 PWA, офлайн и уведомления
- **PWA + офлайн**: service worker кеширует оболочку и последний прогноз — работает без сети
- **Установка на экран**: манифест, иконки, `beforeinstallprompt`, iOS-мета
- **Погодные уведомления** — локальные алерты по прогнозу (гроза, дождь, жара/холод,
  ветер, туман) + готовый к Web Push service worker

### 🎨 Удобство
- **3 языка** (RU / EN / ES) · **3 темы** (адаптивная / тёмная / светлая)
- Метрические/имперские единицы · выбор модели данных (Auto / ECMWF / GFS / ICON)
- Поиск с автодополнением, избранное, недавние города, геолокация
- Автообновление каждые 15 минут · доступность с клавиатуры · `prefers-reduced-motion`

## 📌 Этап разработки (актуальный PR)

Текущая ветка `arena/01a00816-livesky` — пакет правок «аудит → починка → оптимизация → точность».
Подробный журнал — в [CHANGELOG.md](CHANGELOG.md). Кратко, что сделано на этом этапе:

**Аудит и починка багов**
- Кнопка «Повторить» в тосте поиска больше не падает (раньше в колбэк попадал объект ошибки).
- Офлайн-режим чинится при «холодном» старте: service worker кеширует статические ассеты
  под ключом без `?v=`, поэтому закешированный сайт открывается с первого визита офлайн;
  кеш больше не разрастается бесконечно (общий ключ + лимит forecast-кеша).
- FPS-детектор больше не крутит `requestAnimationFrame` вечно — останавливается в фоне
  вкладки и вне режима «Авто» (меньше расход батареи).
- Исправлен цвет текста «Светлая» в меню выбора темы (конфликт атрибута `data-theme`
  с CSS-токенами; переименован в `data-theme-pick`).
- Manifest: ориентация установленного приложения стала `any` (не запирается в портрет).

**Smart Visibility v2 — настоящая оптимизация**
- У далёких секций тяжёлый DOM **реально отсоединяется** и заменяется лёгким
  скелетоном (высота сохраняется — скролл не прыгает).
- При возврате карточка вставляется обратно без перерисовки; разгруженные секции при
  обновлении данных не перестраивают DOM, а перерисовываются лениво при возврате.
- Адаптивный debounce разгрузки (быстрее в Eco / на слабых устройствах).

**Карта и радар**
- Исправлен радар: размер тайлов теперь совпадает с `tileSize` источника (на телефонах
  слой больше не «плывёт» из-за 512px/256px рассинхрона), при включении радара карта
  отъезжает на zoom 7 (данные осадков есть до этого уровня), слой добавляется после
  готовности стиля с ретраями.

**Точность прогноза**
- Региональная модель в «Авто» (ECMWF/Европа, GFS/Северная Америка) + `best_match`.
- Интерполяция текущей температуры и «ощущается» между часовыми срезами.

**Гигиена / полировка**
- `favicon.ico` ужат с 250 КБ до ~32 КБ; Phosphor-иконки закреплены по версии и грузятся
  с `defer`; модалки получили фокус-ловушку, `inert`-фон и возврат фокуса.
- README приведён в соответствие с фактическим поведением.

> **Планы / следующий этап:** nowcast Open-Meteo на первые 1–2 ч (15-минутная сетка) —
> намеренно отложен, чтобы не ломать рабочее приложение одним заходом.

## 🚀 Запуск локально

Проект полностью статический — достаточно открыть `docs/index.html`. Для работы
PWA/service worker и карт удобнее HTTP-сервер:

```bash
python3 -m http.server 8000 --directory docs
# → http://localhost:8000
```

### Установка как приложения (PWA)

- **Android / Chrome / Edge / Desktop** — значок «Установить» в адресной строке
  или кнопка «Установить приложение» в меню LiveSky
- **iOS Safari** — «Поделиться» → «На экран "Домой"»
- **Офлайн** показывается последний кешированный прогноз

### Сборка Android APK (Capacitor)

Нативный проект находится в `android/`. Требования для локальной сборки:
Node.js 22+, JDK 21+ и Android SDK 36.

```bash
npm ci
npm run cap:sync       # скопировать docs/ и обновить нативные плагины
npm run android:build  # debug APK
npm run android:open   # открыть проект в Android Studio
```

Debug APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Для Google Play используйте `npm run android:bundle` и настройте release-подпись через
локальный keystore — файлы `*.jks`, `*.keystore` и `android/key.properties` исключены из Git.
Иконки и splash-экраны вновь можно создать командой `./scripts/generate-android-assets.sh`
(нужен ImageMagick).

#### Производительность Android

APK отображает тот же интерфейс внутри **Android System WebView**, а сайт — непосредственно
в Chrome. Версии движка, GPU-композитинг и оптимизация `backdrop-filter`/Canvas на устройстве
могут отличаться, поэтому debug APK иногда работает тяжелее сайта. На слабых телефонах
выберите в меню **Производительность → Эконом**: приложение отключит погодный Canvas,
движущиеся фоновые пятна и снизит размытие карточек. Режим **Авто** также переключается на
облегчённый профиль, если FPS устойчиво падает.

## 🧪 Тестирование

```bash
npm install
npm test        # 106 проверок: веб-рендеринг, Capacitor, свайп, модалки, темы и отказы
```

Включая сценарии отказов: зависшая сеть (watchdog скрывает загрузчик), отсутствующие
элементы страницы, пропавший скрипт локализации — вместо вечного лоадера панель ошибок.

## 🛡️ Надёжность

- Все `fetch` с таймаутами (AbortController) — ни один запрос не зависает
- Watchdog загрузчика — экран загрузки не может остаться навсегда
- Аварийная панель с кнопками **«Перезагрузить»** и **«Сообщить об ошибке»**
- Автодоклад о багах: при ошибке сети/сбое появляется кнопка-баг, ведущая на GitHub Issues
- Санитизация настроек из localStorage · защита от устаревшего кеша (версии ассетов)
