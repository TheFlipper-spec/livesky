# LiveSky Weather Pro

## ✨ Что нового в релизе 1.4 Alpha

### 🔔 Продуманная система уведомлений (Web PWA + Android)
- **Умная приоритезация без спама:** гроза, град, штормовой ветер, метель, гололёд, ливень, густой туман и экстремальный УФ-индекс ранжируются по опасности и близости во времени (не более одного экстренного оповещения за цикл проверки).
- **Ночной режим тишины (`23:00–06:30`):** некритичные уведомления не беспокоят ночью; в часы тишины проходят только штормовые предупреждения высокого ранга на ближайшие 3 часа.
- **Поминутный Nowcast осадков (за 15–60 минут):** анализирует 15-минутную сетку Open-Meteo и радарный оптический поток, предупреждая о начале дождя или снега с точным временем и советом по экипировке.
- **Детектор резкого похолодания и гололедицы:** предупреждает о падении температуры на 8°C и более, а также о замерзании мокрой дороги при переходе через 0°C.
- **Утренние (`06:30–12:00`) и вечерние (`18:00–22:59`) сводки:** включают диапазон температур, вероятность осадков, сравнение с предыдущим днём и краткую рекомендацию «Что надеть» (на Android планируются в фоне через `LocalNotifications`).

### 🧥 Многофакторный советник «Что надеть» (`buildSmartWearAdvice`)
- **Эффективная температура комфорта:** учитывает `apparent_temperature` (ощущаемую температуру), охлаждение ветром (windchill), влажность, точку росы и тренд температуры на ближайшие 6 часов.
- **9 точных температурных уровней** (от экстремального мороза `< −18°C` до жары `≥ +27°C`) + специализированные комплекты для **бега** и **прогулок** в разделе **LifeSky · Активности**.
- **Защита от выворачивания зонта:** если ожидается дождь при порывах ветра ≥ 13 м/с (~47 км/ч), советник предупредит об опасности сломать зонт и порекомендует непромокаемую куртку с капюшоном или дождевик.
- **Контроль гололедицы и обуви:** при температуре около 0°C (`−4.5°C .. +2.5°C`) с осадками напоминает надеть непромокаемую обувь с цепким нескользящим протектором.
- **Контроль вечернего похолодания:** подскажет захватить дополнительную кофту или куртку, если в ближайшие 6 часов похолодает на 5°C и более.

### 🎨 Кастомизация, Студия темы и чистый минимализм
- **Монохромная чёрно-белая Светлая тема (`[data-theme="light"]`):** строгая графитовая эстетика на чисто белом фоне без цветного шума и без фоновых частиц Canvas.
- **Студия темы (`12-theme-studio.js`):** настройка цветов фона, карточек, прозрачности и размытия стекла, акцентов, кнопок, контуров и графика температуры с проверкой контраста **WCAG AA/AAA** и экспортом/импортом JSON.
- **Смена цвета иконки приложения:** тонирование фирменного логотипа ветра `LiveSky_icon.png` в любой цвет из пресетов или системной палитры с автоматическим обновлением фавикона и PWA-иконки через Service Worker.

## 🌦️ Ключевые возможности LiveSky

| Модуль | Возможности |
| :--- | :--- |
| **Поминутный и 16-дневный прогноз** | Плавная интерполяция температуры между часами, 15-минутная лента осадков на 6 часов, почасовой прогноз на 24 часа, прогноз на 7/16 дней и архив за 16 дней. |
| **Гибридная карта осадков** | Векторная карта **MapLibre GL + OpenFreeMap** в цветах активной темы + спутниковый слой **NASA GIBS IMERG** + радар **RainViewer** + клиентский расчёт движения осадков (optical-flow nowcast). |
| **Интерактивный 24ч график** | Плавная кривая температуры с перетаскиванием пальцем или мышью, поминутной интерполяцией и штриховкой зон дождя, снега и грозы. |
| **Качество воздуха (EAQI)** | Европейский индекс качества воздуха, уровни PM2.5, PM10, O₃ и NO₂, почасовая динамика на 24 часа и советы для здоровья. |
| **LifeSky · Активности** | Индекс от 0 до 100 для **Бега**, **Мойки авто** и **Прогулки** прямо сейчас и подбор лучших слотов на 7 дней вперёд. |
| **Полный офлайн-доступ** | Service Worker сохраняет оболочку приложения и последние загруженные прогнозы + резервная база снапшотов городов. |

## 🗂️ Архитектура проекта

```text
livesky/
├── docs/                           # Веб-приложение (GitHub Pages + Capacitor webDir)
│   ├── index.html                  # Точка входа и семантическая разметка
│   ├── manifest.webmanifest        # Манифест Progressive Web App
│   ├── sw.js                       # Service Worker (офлайн-кеш + кастомные иконки PWA)
│   ├── css/app.css                 # Дизайн-система, адаптивная сетка, Ч/Б тема и Студия темы
│   ├── icons/                      # Иконки приложения и оригинальный силуэт LiveSky_icon.png
│   └── js/
│       ├── i18n.js                 # Локализация (RU / EN / ES) и справочник кодов WMO
│       └── modules/                # Слоистая модульная архитектура:
│           ├── 01-core.js          # Ядро: state, DOM-кэш, форматирование, время и часовые пояса
│           ├── 02-weather-data.js  # Запросы к Open-Meteo, резервные хосты, геокодинг и снапшоты
│           ├── 03-rendering.js     # Главная карточка, 15-минутный блок, компас ветра и солнце
│           ├── 04-chart.js         # 24-часовой интерактивный график температуры и осадков
│           ├── 05-hourly-alerts.js # Почасовая/недельная ленты и детектор опасных явлений
│           ├── 06-air.js           # Карточка и модальное окно качества воздуха (EAQI)
│           ├── 07-effects.js       # Погодные темы, закатный переход (dusk glide) и Canvas FX
│           ├── 08-search-modals.js # Модальные окна, советник «Что надеть», LifeSky и настройки
│           ├── 09-lifecycle.js     # Монитор FPS/батареи, секционный рендеринг, живые тикеры
│           ├── 10-bootstrap.js     # Инициализация, умные уведомления, PWA и мост Capacitor
│           ├── 11-map-radar.js     # Ленивый модуль карты MapLibre + гибридный радар осадков
│           └── 12-theme-studio.js  # Интерактивная Студия темы с живым превью и экспортом JSON
├── android/                        # Нативный Android-проект (Capacitor 8, SDK 36)
├── scripts/                        # Скрипты сборки JS, APK и локального dev-сервера
└── tests/smoke.js                  # Интеграционный и регрессионный тест-сьют (JSDOM)
```

## 🚀 Разработка и сборка

### Локальный запуск
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера (http://localhost:8080)
npm run serve

# 3. Прогон интеграционных smoke-тестов
npm test
```

### Сборка Android APK
```bash
# Синхронизация веб-ресурсов из docs/ в android/
npm run cap:sync

# Сборка Debug APK (требуется JDK 21 и Android SDK 36)
npm run android:build

# Сборка подписанного Release APK
npm run android:release
```
