# LiveSky Weather Pro — 1.4 Alpha

**LiveSky Weather Pro** — веб-приложение (PWA) и нативное Android-приложение для прогноза погоды с живыми обновлениями, гибридной картой осадков, умным гардеробным советником, контекстными уведомлениями и глубокой кастомизацией интерфейса.

🌐 **Онлайн-версия:** [theflipper-spec.github.io/livesky](https://theflipper-spec.github.io/livesky/)

---

## Что нового в версии 1.4 Alpha

- **Умная система уведомлений (Web PWA + Android LocalNotifications):**
  - **Экстренные предупреждения по приоритету:** гроза, град, штормовой ветер, метель, гололёд, ливень, туман и экстремальный УФ-индекс с защитой от спама (не более одного самого важного уведомления за цикл проверки).
  - **Ночной режим тишины (23:00–06:30):** некритичные уведомления откладываются до утра; ночью проходят только жизнеугрожающие штормовые предупреждения на ближайшие 3 часа.
  - **Минутный радар и nowcast-оповещения:** точное предупреждение о начале дождя или снега за 15–60 минут (по 15-минутной сетке Open-Meteo и оптическому потоку радара) с подсказкой взять зонт или надеть куртку с капюшоном при сильном ветре.
  - **Детектор резкого похолодания и гололедицы:** автоматическое предупреждение, если температура упадёт на 8°C и более за ближайшие часы или перейдёт через 0°C в минус после дождя/мокрого снега.
  - **Утренние (06:30–12:00) и вечерние (18:00–22:59) сводки с советом «Что надеть»:** включают диапазон температур, вероятность осадков, сравнение со вчерашним/сегодняшним днём и краткую рекомендацию по одежде (на Android также планируются заранее через `LocalNotifications`).
- **Многофакторный советник «Что надеть» и анализ погоды (`buildSmartWearAdvice`):**
  - Рассчитывает **эффективную ощущаемую температуру** с учётом ветрового охлаждения (windchill), влажности, точки росы и тренда температуры на ближайшие 6 часов.
  - **9 детальных температурных уровней** (от экстремального мороза ниже −18°C до жары выше +27°C) + специализированная экипировка для бега и прогулок в **LifeSky · Активности**.
  - **Умный выбор защиты от осадков и ветра:** если ожидается дождь при порывах ветра ≥ 13 м/с (~47 км/ч), система предупредит, что зонт может вывернуть, и порекомендует непромокаемую куртку с капюшоном или дождевик.
  - **Контроль покрытия дорог и обуви:** предупреждает о гололедице и мокрой снежной каше при температуре около 0°C, рекомендуя непромокаемую обувь с нескользящим протектором.
  - **Предупреждение о перепадах температуры:** подскажет захватить дополнительный слой на вечер, если в ближайшие 6 часов похолодает на 5°C и более.
- **Минималистичная чёрно-белая Светлая тема (`[data-theme="light"]`):**
  - Строгая монохромная палитра (чистый белый фон, графитово-чёрная типографика, контрастные контуры и монохромные погодные иконки) без фоновых частиц, бликов и отвлекающих эффектов.
- **Студия темы (`12-theme-studio.js`) и кастомизация иконки приложения:**
  - Полноценный визуальный редактор собственной темы в реальном времени (фон страницы, карточки, прозрачность и размытие стекла, акценты, кнопки, обводки, график температуры, проверка контрастности WCAG AA/AAA, экспорт и импорт JSON).
  - Смена цвета фирменного логотипа и иконки приложения (PWA и фавикона) с тонированием оригинального силуэта `LiveSky_icon.png` и кешированием в Service Worker.

## Основные возможности

- **Живой прогноз в реальном времени:** температура, ощущаемая температура, плавная интерполяция между часами, поминутный прогноз осадков на 6 часов (шаг 15 минут), почасовой прогноз на 24 часа, прогноз на 7 и 16 дней + архив погоды за 16 дней.
- **Интерактивный 24-часовой график (`04-chart.js`):** плавная кривая Белье с поддержкой перетаскивания (touch/mouse/клавиатура), поминутной интерполяцией и отображением зон дождя, снега и грозы.
- **Гибридная карта осадков (`11-map-radar.js`):**
  - Векторная подложка **MapLibre GL** + **OpenFreeMap**, адаптирующаяся под цветовую тему приложения.
  - Объединение спутниковых данных **NASA GIBS IMERG** (глобальное покрытие) и радарных снимков **RainViewer** с собственным расчётом оптического потока (optical-flow nowcast) для плавной анимации и прогноза движения осадков.
- **Качество воздуха (`06-air.js`):** Европейский индекс качества воздуха (EAQI), детализация по PM2.5, PM10, O₃ и NO₂, почасовой тренд на 24 часа и рекомендации для здоровья.
- **LifeSky · Активности:** оценка условий от 0 до 100 для **бега**, **мойки автомобиля** и **прогулки** прямо сейчас и поиск лучших временных слотов на 7 дней вперёд.
- **Офлайн-режим (PWA):** Service Worker кеширует оболочку приложения и последние загруженные прогнозы для мгновенного холодного старта без сети.
- **Мультиязычность и системы единиц:** полная поддержка **Русского**, **English** и **Español**, метрических (°C, км/ч, гПа, мм) и имперских (°F, миль/ч, дюйм.рт.ст.) единиц, а также выбор метеомодели (**Auto Best Match**, **ECMWF**, **GFS**, **ICON**).

## Быстрый старт и разработка

### Требования
- **Node.js** 18+ (рекомендуется Node 20/22)
- **Python 3** (опционально, для локального сервера `npm run serve`)

### Установка и запуск
```bash
# Установка зависимостей
npm install

# Запуск локального сервера (http://localhost:8080)
npm run serve

# Запуск полного набора интеграционных smoke-тестов
npm test

# Пересборка бандла docs/js/app.js из docs/js/modules/*.js
npm run build:js
```

## Сборка Android APK (Capacitor)

Проект настроен для сборки нативного Android-приложения (`io.github.theflipperspec.livesky`, версия **1.4 Alpha**):

```bash
# Синхронизация веб-ресурсов из docs/ в android/
npm run cap:sync

# Сборка Debug APK (требуется JDK 21 и Android SDK 36)
npm run android:build

# Сборка подписанного Release APK
npm run android:release
```

Для облачной сборки и автоматической публикации релиза в GitHub Releases настроен workflow [`.github/workflows/android-release-manual.yml`](.github/workflows/android-release-manual.yml) (`Actions → Android Release Build (Manual) → Run workflow`).
