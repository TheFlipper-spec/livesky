# LiveSky — Weather Pro 🌤

Премиальное погодное веб-приложение: адаптивные погодные фоны, тематические анимации,
графики, качество воздуха и прогноз активностей. Полностью на фронтенде,
данные — [Open-Meteo](https://open-meteo.com/).

## Возможности

- **Живой фон**: градиенты и canvas-эффекты под текущую погоду (дождь, снег, туман, облака,
  звёзды с падающими метеорами, молнии при грозе)
- **График температуры на 24 часа** с осадками, порывами ветра и интерактивным тултипом
- **Солнечная дуга**: положение солнца/луны, долгота дня, фаза луны, «золотой час»
- **Качество воздуха**: европейский индекс AQI (PM2.5, PM10, O₃, NO₂)
- **Почасовой и 16-дневный прогноз + история за 16 дней** с температурными диапазонами
- **LifeSky-активности**: лучшие слоты для бега, мойки авто и прогулок
- **Карта**: выбор любого места кликом (Leaflet + OSM), светлая/тёмная подложка;
  перетаскивание карты не открывает модалку
- **Поиск с автодополнением, избранное, недавние города, геолокация**
- **3 языка** (RU / EN / ES), **3 темы** (адаптивная / тёмная / светлая),
  метрические/имперские единицы, выбор модели (Auto / ECMWF / GFS / ICON) —
  всё собрано в **одной кнопке меню**, чтобы не перегружать шапку
- Оповещения об опасной погоде, тосты с повтором при ошибке сети,
  прогресс-бар, поддержка `prefers-reduced-motion`, доступность с клавиатуры

### Умные детали

- Цвет температуры меняется по её значению (мороз → жара)
- Тренд давления (↗ растёт / ↘ падает за 3 часа), порывы ветра
- Чип «Дождь в ближайший час», высота над уровнем моря, направление ветра-компас
- Автообновление данных каждые 15 минут, защита от «гонки» запросов
- Миграция избранного и последнего города из LiveSky v1
- Навигация по автокомплиту стрелками, кнопка очистки поиска,
  блокировка прокрутки фона под модалками
- Хоткей `/` — фокус в поиск, `Esc` — закрытие окон, `←`/`→` — прокрутка часов

## Структура

```
docs/
├── index.html     — разметка
├── css/app.css    — дизайн-система (токены, стекло, анимации, адаптив)
└── js/
    ├── i18n.js    — словари RU/EN/ES + коды погоды WMO
    └── app.js     — логика приложения
tests/
└── smoke.js       — smoke-тест приложения (jsdom + реальные данные Open-Meteo)
```

### Тесты

```bash
npm install && npm test   # 36 проверок: рендеринг, модалки, темы, поиск, хранилище
```

## Запуск

Просто откройте `docs/index.html` в браузере, либо локально:

```bash
python3 -m http.server 8000 --directory docs
```

## Данные

- Прогноз и геокодинг: [Open-Meteo](https://open-meteo.com/) (бесплатно, без ключей)
- Качество воздуха: Open-Meteo Air Quality API
- Обратное геокодирование: Nominatim / BigDataCloud
- Карты: [Leaflet](https://leafletjs.com/) + CartoDB / OpenStreetMap
- Иконки: [Phosphor Icons](https://phosphoricons.com/), шрифты: Google Fonts (Unbounded, Montserrat)
