# LiveSky — Weather Pro 🌤

Премиальное погодное веб-приложение: адаптивные погодные фоны, тематические анимации,
графики, качество воздуха, радар осадков и офлайн-доступ. Полностью на фронтенде,
данные — [Open-Meteo](https://open-meteo.com/).

> ### 🚀 Зайти на сайт
> **[https://theflipper-spec.github.io/livesky/](https://theflipper-spec.github.io/livesky/)**

## Возможности

- **PWA + офлайн**: service worker кеширует оболочку приложения и последний прогноз,
  сайт можно «установить» на рабочий стол/экран смартфона (иконки, манифест,
  `beforeinstallprompt`); офлайн показывается последний загруженный прогноз
- **Адаптивная производительность**: детектор FPS автоматически отключает тяжёлые
  эффекты (canvas-частицы, молнии, размытие) на слабых устройствах; ручной режим
  «Максимум / Эконом» — в меню
- **Радар осадков** (RainViewer): поверх полноэкранной карты с таймлайном
  (слайдер по кадрам за последние часы + nowcast, play/pause, легенда)
- **Живой фон**: градиенты и canvas-эффекты под текущую погоду (дождь, снег, туман, облака,
  звёзды с падающими метеорами, молнии при грозе)
- **График температуры на 24 часа** с осадками, порывами ветра и интерактивным тултипом
- **Солнечная дуга**: положение солнца/луны, долгота дня, фаза луны, «золотой час»
- **Качество воздуха**: европейский индекс AQI (PM2.5, PM10, O₃, NO₂)
- **Почасовой и 16-дневный прогноз + история за 16 дней** с температурными диапазонами
- **LifeSky-активности**: лучшие слоты для бега, мойки авто и прогулок
- **Карта**: MapLibre GL с надёжными растровыми тайлами (CARTO под тему + фолбэк OSM),
  плавные полёты камеры, выбор места кликом, пульсирующий пин;
  перетаскивание карты не открывает модалку, геолокация — в едином меню
- **Поиск с автодополнением, избранное, недавние города, геолокация**
- **3 языка** (RU / EN / ES), **3 темы** (адаптивная / тёмная / светлая),
  метрические/имперские единицы, выбор модели (Auto / ECMWF / GFS / ICON) —
  всё собрано в **одной кнопке меню**, чтобы не перегружать шапку
- Оповещения об опасной погоде, тосты с повтором при ошибке сети,
  прогресс-бар, поддержка `prefers-reduced-motion`, доступность с клавиатуры

### Умные детали

- Цвет температуры меняется по её значению (мороз → жара)
- Тренд давления (↗ растёт / ↘ падает за 3 часа), порывы ветра
- Чип «Дождь в ближайший час», высота над уровнем моря, направление ветра-компас
- Автообновление данных каждые 15 минут, защита от «гонки» запросов
- Миграция избранного и последнего города из LiveSky v1
- Навигация по автокомплиту стрелками, кнопка очистки поиска,
  блокировка прокрутки фона под модалками
- Хоткей `/` — фокус в поиск, `Esc` — закрытие окон, `←`/`→` — прокрутка часов

## Структура

```
docs/
├── index.html              — разметка
├── css/app.css             — дизайн-система (токены, стекло, анимации, адаптив)
├── js/
│   ├── i18n.js             — словари RU/EN/ES + коды погоды WMO
│   └── app.js              — логика приложения (в т.ч. PWA, FPS, радар)
├── manifest.webmanifest    — PWA-манифест (иконки, standalone, theme)
├── sw.js                   — service worker (кеш оболочки + последний прогноз)
└── icons/                  — иконки приложения (16…512 px)
tests/
└── smoke.js                — smoke-тест приложения (jsdom + реальные данные Open-Meteo)
```

### Тесты

```bash
npm install && npm test   # 92 проверки: рендеринг, модалки, темы, поиск, хранилище
```

Включая сценарии отказов: зависшая сеть (watchdog скрывает загрузчик и предлагает повторить),
отсутствующие элементы страницы (graceful degradation), пропавший скрипт локализации
(панель ошибки вместо вечного лоадера).

### Надёжность

- Все сетевые запросы с таймаутами (AbortController) — ни один `fetch` не может зависнуть
- Watchdog загрузчика: экран загрузки не может остаться навсегда
- Аварийная панель с кнопкой перезагрузки вместо бесконечного лоадера
- Санитизация настроек из localStorage, защита от устаревшего кеша (версии ассетов)

## Запуск

**Онлайн:** откройте **https://theflipper-spec.github.io/livesky/**

Локально — достаточно открыть `docs/index.html`, либо поднять HTTP-сервер
(нужен для PWA/service worker и карт):

```bash
python3 -m http.server 8000 --directory docs
```

### Установка как приложения (PWA)

- **Android / Chrome / Edge / Desktop**: в адресной строке появится значок «Установить»
  (или кнопка «Установить приложение» в меню LiveSky). Работает офлайн после первого открытия.
- **iOS Safari**: «Поделиться» → «На экран “Домой”».
- Офлайн показывается последний загруженный прогноз (кеш оболочки + последние данные).

## Данные

- Прогноз и геокодинг: [Open-Meteo](https://open-meteo.com/) (бесплатно, без ключей)
- Качество воздуха: Open-Meteo Air Quality API
- Радар осадков: [RainViewer](https://www.rainviewer.com/) (погодные карты)
- Обратное геокодирование: Nominatim / BigDataCloud
- Карты: [MapLibre GL](https://maplibre.org/) + OpenMapTiles / OpenStreetMap (фолбэк: CartoDB)
- Иконки: [Phosphor Icons](https://phosphoricons.com/), шрифты: Google Fonts (Unbounded, Montserrat)
