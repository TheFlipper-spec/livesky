Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено] — юридический слой

### 🔐 Последовательные согласия (Sequential Consent)
- **Шаг 1 (хард-блок):** только Пользовательское соглашение, кнопка «Принять и продолжить».
  Прогнозы вероятностные, AS IS, LiveSky не МЧС. `livesky:tos_accepted` + `livesky:legal_consent` v3.0.
- **Шаг 2 (софт-блок):** сразу после ToS — запрос геолокации и ссылка на Политику.
  «Разрешить» → `privacy_accepted: true` и автозапрос Geolocation API.
  «Отказаться» → `privacy_accepted: false`, дефолтный/последний город, приложение полностью работает.
- Повторный запрос — по кнопке «Моё местоположение», если пользователь раньше отказался.
- Возврат со страницы Terms требует свежий ToS (`?consent=required`). Privacy приложение не блокирует.

### 📄 Политика конфиденциальности
- Формулировка о передаче данных обновлена: координаты не сохраняются на серверах LiveSky и
  передаются только доверенным внешним провайдерам API (Open-Meteo, Nominatim, RainViewer)
  в момент использования; профилирование и маркетинг исключены.
- Добавлен корневой `PRIVACY.md` (markdown-зеркало `docs/legal/privacy.html`).

## [В разработке] — ветка `arena/01a021e3-livesky`

### ⏱ Минутная точность
- Open-Meteo `minutely_15` nowcast для статуса дождя/снега («закончится через N мин · в HH:MM»).
- График «Температура · 24 часа»: поминутный scrub (мышь + палец), интерполяция метрик.
- Окна дождя/снега/грозы: штриховка *под* кривой температуры (aspect-corrected diagonal hatch),
  HTML-бейджи без деформации, чипы `HH:MM–HH:MM` (границы из minutely_15).
- Live-тик UI каждую минуту + тихий network refresh ~3 мин.

### 🗺️ Карта осадков
- RainViewer dual-layer cross-fade (без мерцания при смене кадра), tileSize 256, maxzoom 7.
- Play/pause, скорость, плотность, Live, автообновление метаданных.

### ⚠️ Опасная погода
- Мульти-hazard движок: гроза, град, ливень, снегопад, метель, гололёд, ветер/шторм,
  жара, мороз, туман, высокий УФ.
- Короткий баннер с минутами: `Гроза · через 23 мин · 15:47` (баннер + local notifications).

### 🫁 Качество воздуха
- Простые подписи («Мелкая пыль», «Выхлопы») и уровни («Норма» / «Много») вместо µg/m³-жаргона.
- Модалка: лучший/худший час, цветная полоска 24ч, шкалы факторов.

### 📱 Мобайл
- Touch-scrub графика, горизонтальный скролл чипов, компактный alert, крупные hit-target’ы.

### 📚 Документация
- README приведён к фактическому поведению; раздел «Насколько верить карте осадков».

## [В разработке] — ветка `arena/01a00816-livesky`

Этап «аудит → починка → оптимизация → точность». Пакет изменений готовится к слиянию
в `main` одним pull request.

### ✨ Точность прогноза
- Режим «Авто» теперь запрашивает `models=best_match` — модель, которую Open-Meteo
  ранжирует как самую точную для конкретной точки и переменной.
- В «Авто» базовая модель выбирается по региону: **ECMWF (IFS)** для Европы
  (включая европейскую часть РФ), **GFS** для Северной Америки, иначе — чистый `best_match`.
- В ручных режимах выбранная модель дополняется `best_match` как запасной (`getVal`
  сначала читает выбранную модель, затем `_best_match`).
- Текущая температура в герое и плитка «Ощущается» **интерполируются** между соседними
  часовыми срезами по минутам текущего времени — значение плавное, а не привязано к целому часу.

### 🗺️ Карта и радар
- **Радар RainViewer**: исправлен рассинхрон размера тайлов и `tileSize` источника
  (на hi-DPI телефонах запрашивались тайлы 512px, но источник был объявлен как 256px —
  из-за этого слой «плыл» и выглядел бессмысленными разводами). Теперь `tileSize`
  всегда совпадает с реальным размером тайла.
- При включении радара карта плавно отъезжает на **zoom 7** — данные осадков RainViewer
  существуют только до этого уровня, на дефолтном zoom 10 радар был невидим/размазан.
- Добавление слоя радара теперь дожидается готовности стиля (`isStyleLoaded`) и повторяет
  попытку (увеличен лимит ретраев) — слой не «молча» пропадает.

### 🐛 Исправления багов
- **Тост «Повторить» в поиске** больше не падает: в колбэк ретрая больше не передаётся
  объект ошибки (у `Error` нет `preventDefault`, что роняло `handleSearch`).
- **Офлайн при холодном старте**: service worker кеширует статические ассеты под ключом
  без `?v=`, поэтому `css/app.css?v=25` и т.п. находят копию в кеше с первого визита;
  офлайн-перезагрузка больше не отдаёт страницу без стилей и логики.
- **Рост кеша**: версии `?v=` больше не плодят записи (общий query-free ключ), forecast-кеш
  ограничен 25 записями (`trimForecastCache`), версия кеша поднята до `livesky-v13`
  (старые раздутые кеши чистятся при активации).
- **FPS-детектор**: добавлен `PERF.stop()` — rAF-цикл останавливается при скрытой вкладке
  и при режиме ≠ «Авто»; в `init()` запускается только на «Авто». Раньше цикл крутился вечно.
- **Цвет «Светлая» в меню темы**: конфликт атрибута `data-theme` с CSS-токенами —
  кнопка выбора темы «включала» себе светлые токены, из-за чего текст был тёмным на тёмном фоне.
  Атрибут кнопок переименован в `data-theme-pick` (на селектор темы это не влияет).
- **Manifest**: `orientation` изменён с `portrait-primary` на `any` — установленное
  приложение не запирается в портретный режим.
- **График при пустом payload**: `renderChart()` теперь очищает устаревшие данные/hover
  вместо «фантомных» точек.

### 🧠 Smart Visibility v2
- **Реальное удаление тяжёлого DOM**: у далёких секций (chart / hourly / daily / lifestyle)
  карточка отсоединяется от документа и заменяется лёгким скелетоном `.section-skeleton-box`
  (высота измеряется у карточки → скролл не прыгает).
- **Мгновенное восстановление**: при возврате кешированная карточка вставляется обратно
  без перерисовки, если данные не менялись (нет мигания).
- **Ленивый re-render**: `renderAll()` гоняет chart/hourly/daily через `renderSection()`;
  разгруженные секции при обновлении данных не перестраивают DOM, а помечаются «грязными»
  и перерисовываются только когда пользователь к ним возвращается.
- **Адаптивный debounce разгрузки** (`unloadDelay`): ~1 с в Eco/low-режиме, 4 с по умолчанию.
- **Без «флеша»**: для вернувшихся секций не повторяется enter-анимация (opacity остаётся 1).

### 🧹 Гигиена / полировка
- `favicon.ico` пересобран: **250 КБ → ~32 КБ** (мультиразмерный 16/32/48/64).
- Phosphor-иконки: закреплена версия `@2.1.2` + `defer`.
- Доступность: модалки и полная карта получили фокус-ловушку, `inert`-фон
  и возврат фокуса на вызвавший элемент при закрытии.
- README приведён в соответствие с фактическим поведением Smart Visibility.
